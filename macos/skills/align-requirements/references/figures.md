# 图

## 先定信息类型，再选图

一张图只讲一种信息。讲不下，就新加一张图。

| 要讲的 | 图 |
|---|---|
| 一件事随时间推进，谁在做 | 泳道：列是角色，行是阶段，真实数据做卡片 |
| 几个概念之间的关系 | 关系图：几样输入汇成一个结果，结果由部件组成，部件取自一个库 |
| 一个带回退的过程 | 流程环：主线向右，回退用虚线弧走在上方，结果存回 |
| 改动对进行中事物的影响 | 版本时间条 |
| 结构和边界：在哪跑，能碰什么 | 分层结构图，往外的边界用一条红色带 |
| 状态在几个主体之间迁移 | 时间线：每个主体一条泳道，中间一条共享状态 |
| 一个派给多个 | 扇出图 |
| 检查点和拦截 | 关卡图：左边是发起方，中间是关卡，右边是能到的地方 |
| 一组规则或原则 | 编号清单，每条注出处 |

## 画的规矩

- 手写内联 SVG，颜色用 template.html 里的 CSS 变量，亮色、暗色都要看。
- 线不压字、不压框；标签放在线旁边，放不下就挪线。
- 颜色有含义就配图例。同一类东西全文同一个颜色：做事的段灰，门禁蓝，人工门橙，同步和接手绿，拦截红，agent 紫。
- 概念图只画一个例子，标「示意」；现有项目、实例的清单留给设计文档。
- 需求改了，图跟着改；只改图下的文字不算改完。

## 动画

在那次对齐里看过效果后定下保留。

- 只给讲时间和流向的图加：接手的时间线、派发。讲结构的图保持静止。
- 滚到图那里播一次，右下角放「重播」按钮；系统开了减少动态效果时直接显示最后一帧。最后一帧就是静态图，打印和截图看到的也是它。
- 写法见 template.html 的 `figure.anim`：元素加 `data-a="in|pop|draw|dim"` 和 `style="--d:秒数s"`。画线动画给 path 加 `pathLength="1"`，箭头单独画一个小三角，比线晚出现。
- 用 `node scripts/shot.mjs <页面> <输出目录> --frames fig6:1.2,3.9` 截中间帧，确认真的在播。
